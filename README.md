# Kayan AI (كيان للذكاء الاصطناعي)

منصة متطورة وحل ذكي للشركات والأفراد، مصممة بواجهة عصرية فخمة تجمع بين تقنيات الذكاء الاصطناعي والعناصر ثلاثية الأبعاد التفاعلية لتجربة مستخدم استثنائية.

## ✨ مميزات المشروع
- **مساعد ذكي تفاعلي:** واجهة ثلاثية الأبعاد تدعم تفاعل المستخدمين بلحظتها.
- **دعم ثنائي اللغة:** واجهة متكاملة باللغتين العربية والإنجليزية.
- **أداء عالي السرعة:** محسن بالكامل للعمل بسلاسة فائقة على أجهزة الكمبيوتر والهواتف الذكية.
- **التواصل الفوري:** ربط مباشر مع خدمات الدردشة وحجز العروض التوضيحية (Demos).

## 🛠️ التقنيات المستخدمة (Tech Stack)
- React & Vite
- TypeScript
- Tailwind CSS
- Spline 3D Integration# kayan-ai
